# 画像の配置方法

このサイトは画像ファイルがなくても動作します（頭文字プレースホルダー表示）。
GPTで作成した画像は、下記のファイル名でこのフォルダに入れるだけで自動表示されます。

## ファイル名ルール

| ファイル名 | 用途 | 推奨サイズ |
|---|---|---|
| `hero.jpg` | トップ・検索・はじめてページのメインビジュアル | 1200×800 |
| `creator-01.jpg` | ランキング1位のクリエイター写真 | 600×640 |
| `creator-02.jpg` | ランキング2位のクリエイター写真 | 600×640 |
| `creator-03.jpg` | ランキング3位のクリエイター写真 | 600×640 |
| ... | ... | ... |
| `creator-12.jpg` | ランキング12位のクリエイター写真 | 600×640 |
