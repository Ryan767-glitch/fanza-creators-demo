# DMM FANZA Creators（デモサイト）

DMM FANZAで活躍するクリエイターを紹介するアフィリエイトメディアのデモサイトです。
デザインカンプ（全10画面）をPC/SPレスポンシブの静的サイトとして再現しています。

## ページ構成

| ファイル | 内容 |
|---|---|
| `index.html` | トップ（ヒーロー＋検索＋おすすめ＋はじめてバナー） |
| `ranking.html` | 人気ランキング（ジャンル絞り込み＋今週の注目＋急上昇） |
| `search.html` | クリエイターを探す（キーワード＋絞り込み＋並び替え＋ページャー） |
| `creator.html?id=xxx` | クリエイター詳細（プロフィール＋作品＋ポイント＋FAQ＋関連） |
| `beginners.html` | はじめての方へ（4ステップ＋安心ポイント＋FAQ） |
| `favorites.html` | お気に入り一覧（ブラウザ保存） |

## 機能

- キーワード検索（名前・かな・ジャンル・タグ・紹介文を横断検索）
- ジャンルタブ / 絞り込み（ジャンル・人気度）/ 並び替え（人気・フォロワー・お気に入り・名前）
- ランキング表示（順位・UP/DOWN・フォロワー数）
- お気に入り登録（localStorage保存、ハートボタン連動）
- FAQアコーディオン、ログインモーダル（デモ）、モバイル用ドロワー＋ボトムナビ

## 使い方

1. このフォルダをそのままWebサーバーに置くか、`index.html` をブラウザで開く
2. 画像を入れる場合は `images/README.md` のファイル名ルールに従って配置
3. アフィリエイトリンクは `js/data.js` の `AFFILIATE_DEFAULT` と各ページの `data-aff` リンクを書き換え
4. クリエイターデータは `js/data.js` の `CREATORS` を差し替え（現在は架空のサンプル12名）

## 注意

- 掲載データはすべて架空のサンプルです。実在の人物・団体とは関係ありません
- 公開時はDMMアフィリエイトの利用規約（商標・表記ルール）を確認してください
